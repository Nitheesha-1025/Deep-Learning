# Deep Learning Laboratory Experiments

This repository contains the implementation of Deep Learning laboratory experiments completed as part of my **B.Tech in Artificial Intelligence & Data Science**. The experiments cover the fundamental concepts of neural networks, deep learning, data preprocessing, model evaluation, and hyperparameter optimization using Python and popular machine learning libraries.

---

## Objectives

- Understand the fundamentals of Deep Learning.
- Implement machine learning and deep learning algorithms from scratch and using TensorFlow/Keras.
- Learn data preprocessing and visualization techniques.
- Evaluate model performance using standard metrics.
- Perform hyperparameter tuning and model optimization.

---

## How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/Deep-Learning-Lab.git
```

2. Navigate to the project

```bash
cd Deep-Learning-Lab
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Open the notebook using Jupyter Notebook or Google Colab and run the cells sequentially.
